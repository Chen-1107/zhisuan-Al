# Multiwfn 使用技能手册（完整指令版）

> 本文档基于 Multiwfn 官方手册（2026.1.12版）及 Quick Start 文档整理，涵盖安装配置、基本操作、**全部主功能（0–1000）及其子功能指令**、实用技巧与常见问题。

## 一、Multiwfn 简介

**Multiwfn**（Multi-Purpose WaveFunction Analyzer）是一款免费、功能极全的量子化学波函数分析程序 \[pdf\_1]，支持：

- 分子结构与轨道可视化

- 100+ 实空间函数分析与绘图

- 拓扑分析（AIM 理论）

- 原子电荷与布居分析（Mulliken、Löwdin、Hirshfeld、ADCH、CM5、RESP、AIM 等）

- 静电势（ESP）分析与分子表面定量分析

- 电子激发分析（hole-electron、NTO、IFCT、密度差、Δr、Λ 等）

- 弱相互作用分析（NCI/RDG、IGM/IGMH、IRI、DORI）

- 振动光谱与电子光谱绘制（IR、Raman、UV-Vis、ECD、VCD、ROA、NMR）

- DOS/COHP 态密度分析

- 轨道定域化与 AdNDP 分析

- 周期性体系分析

- 能量分解分析（EDA-FF、EDA-SBL）

- 电荷分解分析（CDA/GCDA）

- **官方网站**：<http://sobereva.com/multiwfn> \[pdf\_2]

- **英文论坛**：<http://sobereva.com/wfnbbs> \[pdf\_2]

- **中文论坛**：<http://bbs.keinsci.com/wfn> \[pdf\_2]

## 二、安装与配置

### 2.1 Windows 版本 \[pdf\_1]

1. 解压程序包即可使用，无需安装。
2. 双击 `Multiwfn.exe` 图标启动。
3. **建议**将 `settings.ini` 中的 `nthreads` 设置为 CPU 物理核心数。
4. 如需直接打开 Gaussian `.chk` 文件，设置 `formchkpath`。
5. 部分功能依赖 Gaussian，需设置 `GAUSS_EXEDIR` 环境变量（见附录 1）。

### 2.2 Linux 版本 \[pdf\_1]

```bash
# 安装 motif 包
# CentOS/Red Hat: yum install motif
# Ubuntu: sudo apt-get install libxm4 libgl1

# 在 ~/.bashrc 中添加：
export OMP_STACKSIZE=1000M
ulimit -s unlimited
export Multiwfnpath=/sob/Multiwfn3.6bin_Linux
export PATH=$PATH:/sob/Multiwfn3.6bin_Linux

# 赋予可执行权限
chmod +x /sob/Multiwfn3.6bin_Linux/Multiwfn

# 检查共享内存大小
cat /proc/sys/kernel/shmmax
# 若太小，在 /etc/sysctl.conf 中添加 kernel.shmmax = 5000000000
```

### 2.3 并行计算配置 \[pdf\_1]

修改 `settings.ini` 中的 `nthreads` 为 CPU 物理核心数。若大体系并行崩溃，增大 `ompstacksize`（Windows 版在 settings.ini 中设置，Linux 版通过 `OMP_STACKSIZE` 环境变量设置）。

## 三、启动与基本操作指令

### 3.1 启动方式 \[pdf\_1]

**交互式启动**：双击 `Multiwfn.exe`，在提示符后输入文件路径。

**命令行启动**：`Multiwfn /sob/test.wfn`

**命令行参数** \[pdf\_1]：

| 参数          | 用途                 | 示例                                    |
| ----------- | ------------------ | ------------------------------------- |
| `-nt N`     | 设置并行线程数            | `Multiwfn test.fch -nt 36`            |
| `-uf N`     | 用户自定义函数索引          | `Multiwfn test.fch -uf 2`             |
| `-silent`   | 静默模式（批处理）          | `Multiwfn test.fch -silent`           |
| `-set PATH` | 指定 settings.ini 路径 | `Multiwfn test.wfn -set /sob/set.ini` |

### 3.2 基本操作指令 \[pdf\_1]

| 操作        | 指令                      | 说明                 |
| --------- | ----------------------- | ------------------ |
| 加载文件      | 输入文件路径（如 `C:/test.fch`） | 启动时或输入 `r` 后       |
| 重新加载文件    | `r`                     | 主菜单输入，无需重启         |
| 退出程序      | `q` 或 `Ctrl+C`          | 优雅退出               |
| 输入文件简写    | 直接输入文件名                 | 当前目录文件无需路径         |
| 使用上次路径    | `l`                     | 加载上次成功读取的文件        |
| 路径简写 `?`  | `?Azusa.fch`            | 用 `?` 代替上次路径       |
| 文件选择窗口    | 直接按 `Enter`（不输入路径）      | 弹出 GUI 文件选择窗口      |
| 显示实空间函数列表 | `$f`                    | 在主功能 1 中列出所有可用函数   |
| 选择轨道      | `$o N`                  | 如 `$o 4` 选择第 4 个轨道 |
| 导出所有内坐标   | `geomparm`              | 在主功能 0 中           |

### 3.3 操作模式 \[pdf\_1]

- **交互模式**（默认）：根据屏幕提示逐步输入指令。

- **静默模式**（`-silent`）：通过输入重定向实现批处理，无需按键。

### 3.4 当前文件夹与文件输出 \[pdf\_1]

- **当前文件夹**：调用 Multiwfn 时所在的路径。

- 导出的文件默认生成在**当前文件夹**中。

- 所有输出数据默认单位为**原子单位（a.u.）**。

## 四、输入文件类型

### 4.1 常用输入文件格式 \[pdf\_1]

| 格式               | 说明                         | 适用场景                     |
| ---------------- | -------------------------- | ------------------------ |
| `.fch` / `.fchk` | Gaussian 格式化 checkpoint 文件 | 最常用，含基函数和轨道信息            |
| `.wfn` / `.wfx`  | 波函数文件                      | 通用波函数分析                  |
| `.molden`        | Molden 格式                  | 支持周期性体系，ORCA 等           |
| `.mwfn`          | Multiwfn 自定义波函数格式          | 保存修改后的波函数                |
| `.out` / `.log`  | Gaussian 输出文件              | 电子激发分析（需含组态系数）           |
| `.cif`           | 晶体结构文件                     | 周期性体系分析                  |
| `.cub` / `.cube` | Gaussian 型网格数据文件           | 加载预计算实空间函数数据             |
| `.grd`           | DMol3 网格文件                 | 网格数据加载                   |
| `.mol` / `.mol2` | 分子结构文件                     | 含连接信息                    |
| `.pdb`           | 蛋白质数据库文件                   | 大分子结构                    |
| `.chg`           | 原子电荷文件                     | 基于原子电荷的 ESP 计算           |
| `.47`            | NBO 文件                     | 含 $FOCK 字段，用于 AdNDP 能量计算 |

### 4.2 电子激发分析所需两类文件 \[pdf\_1]

1. **基函数与轨道信息文件**（启动时加载）：`.fch`、`.mwfn`、`.molden` 或 `.gms` 文件
2. **组态系数文件**（进入分析功能时加载）：Gaussian `.out` 文件、ORCA 输出文件等

### 5.2 主功能 0 — 分子结构与轨道可视化 \[pdf\_1]

**进入方式**：加载文件后，在主菜单输入 `0`

**GUI 操作说明**：

- 点击 `Orbital info.` → 打印轨道信息

- 右下角列表框列出所有轨道索引，点击某一轨道立即显示等值面（绿色为正，蓝色为负）

- `Isovalue` 滑块控制等值面值

- `Isosur. quality` 滑块控制网格质量（越大越平滑）

- `Other settings` → `Set extension distance` 设置扩展距离（用于显示 Rydberg 轨道）

- `Other settings` → `Set lighting` 调节光照

- `Other settings` → `Set atomic label color` 设置原子标签颜色

**测量几何**：

- 输入 2 个原子索引 → 键长

- 输入 3 个原子 → 键角

- 输入 4 个原子 → 二面角

**显示样式切换**（`Other settings`）：

- `CPK 样式`：空间填充模型

- `vdW 样式`：范德华球模型

- `Line 样式`：线框模型

**其他指令**：

- 输入 `geomparm`：导出所有内坐标到文件

- `Print fractional coordinates`：仅当有晶胞信息时可用，打印分数坐标

- 输入 `s`：保存当前绘图设置

- 输入 `l`：加载绘图设置

- `Bonding threshold` 滑块：调节成键判断阈值（默认 CSD 共价半径之和 × 1.15）

***

### 5.3 主功能 1 — 计算单点性质 \[pdf\_1]

**进入方式**：在主菜单输入 `1`

**操作流程**：

1. 输入某点坐标或原子索引
2. 屏幕输出该点处所有实空间函数值、梯度、Hessian 矩阵
3. 若指定函数为电子密度，还输出应力张量及其特征值、应力张量刚度和极化率

**特殊指令**：

- `$f`：列出所有可用实空间函数

- `$f N`：切换要显示梯度的函数（如 `$f 9` 选择 ELF）

- `$o N`：选择轨道（如 `$o 4` 选择第 4 个轨道）

**原子核位置 ESP**：当请求原子核位置的性质时，自动输出**去除了该原子核贡献的 ESP**（即 Vn，可用于预测 pKa 和弱相互作用能）。

***

### 5.4 主功能 2 — 拓扑分析（AIM 理论）\[pdf\_1]

**进入方式**：在主菜单输入 `2`

**可分析函数**：电子密度、Laplacian、轨道波函数、自旋密度、ELF、LOL、ESP 等任意平滑实空间函数。

**搜索临界点（CP）的方式**：

- `1`：从给定起始点搜索（可输入坐标、原子索引中点、`.pdb`/`.pqr` 文件、`.txt` 文件）

- **多种搜索模式**参见手册 3.14.2

**子功能选项**：

- `-11`：切换实空间函数（改变后清除之前的拓扑分析结果）

- `7`：在指定 CP 或所有 CP 处计算实空间函数值（含梯度、Hessian）

- `8`：生成拓扑路径（连接 CP 的曲线）

- `9`：另一种拓扑路径生成方式

- 输出后可在 3D GUI 窗口中直接可视化

**芳香性指标**：基于电子密度拓扑性质计算芳香性指数（3.14.6）。

***

### 5.5 主功能 3 — 沿一维线绘图 \[pdf\_1]

**进入方式**：在主菜单输入 `3`

**操作流程**：

1. 选择一个实空间函数
2. 定义一条线：

   - **方式 1**：输入两个原子索引，线自动向两端延伸（延伸距离由 `aug1D` 参数控制，默认 1.5 Bohr）

   - **方式 2**：输入两个端点的坐标
3. 曲线图自动显示

**特殊选项**：

- `0`：自定义运算（对多个波函数进行 +、-、×、÷）

- `-1`：promolecular 性质

- `-2`：deformation 性质

***

### 5.6 主功能 4 — 平面填色图 \[pdf\_1]

**进入方式**：在主菜单输入 `4`

**操作流程**：

1. 选择一个实空间函数
2. 定义平面（8 种模式）：

| 模式 | 定义方式            | 说明           |
| -- | --------------- | ------------ |
| 1  | XY 平面           | 输入 Z 值       |
| 2  | XZ 平面           | 输入 Y 值       |
| 3  | YZ 平面           | 输入 X 值       |
| 4  | 三个原子            | 输入三个原子索引确定平面 |
| 5  | 三个点             | 输入三个点的坐标     |
| 6  | 原点和两个平移向量       | 需正交          |
| 7  | 平行于某键且垂直于某平面    | 需指定原子        |
| 8  | 在特定原子组成的平面上方/下方 | 需指定原子和偏移量    |

1. 填色图自动显示
2. 输入 `s` 保存设置，输入 `l` 加载设置

**隐藏选项**：

- `111`：绘制 Becke 权重或 Becke 重叠权重

- `112`：绘制 Hirshfeld 权重

**特殊选项**（同主功能 3）：

- `0`：自定义运算

- `-1`：promolecular 性质

- `-2`：deformation 性质

***

### 5.7 主功能 5 — 网格数据与三维等值面 \[pdf\_1]

**进入方式**：在主菜单输入 `5`

**操作流程**：

1. 选择一个实空间函数
2. 设置网格参数（范围、间距）
3. 计算网格数据
4. 自动显示三维等值面
5. 可导出为 `.cub` 文件（用 VMD、VESTA 等可视化）

**模式 9**（仅当输入文件含晶胞信息时）：设置原点、box 长度和网格间距，直接计算周期性体系的网格数据，支持积分计算。

**特殊选项**（同主功能 3/4）：

- `0`：自定义运算（多个波函数 +、-、×、÷）

- `-1`：promolecular 性质

- `-2`：deformation 性质

### 5.10 主功能 8 — 轨道成分分析 \[pdf\_1]

**进入方式**：在主菜单输入 `8`

**完整子功能列表**：

| 子功能 | 指令    | 说明                               |
| --- | ----- | -------------------------------- |

| 2   | `2`   | Stout-Politzer 方法                |
| 3   | `3`   | SCPA 方法                          |
| -1  | `-1`  | 定义片段 1                           |
| -2  | `-2`  | 定义片段 2                           |

| 子功能 | 指令   | 说明                                    |
| --- | ---- | ------------------------------------- |
| 14  | `14` | 从原子波函数生成 `.rad` 文件（用于 Hirshfeld-I 电荷） |
| 17  | `17` | 构建 promolecular 波函数并存入内存              |
| 18  | `18` | 设置网格数据的 box 信息为晶胞信息                   |
| 92  | `92` | 计算全空间动能泛函积分（支持多种 KED 形式）              |

**子功能 92 的** **`iKEDsel`** **参数**：

- `1`：Hamiltonian KED（同实空间函数 6）

- `24`：GEA4 KED（需 Laplacian）

- 其他：仅需电子密度及其梯度

## 八、实用技巧

### 8.1 快速加载文件 \[pdf\_1]

- 当前目录文件：直接输入文件名

- 上次文件：输入 `l`

- 同目录简写：`?filename`

- 换文件不重启：在主菜单输入 `r`

- 文件选择窗口：启动时直接按 `Enter`

### 8.2 静默模式与批处理 \[pdf\_1]

```bash
Multiwfn input.fch -silent < commands.txt
```

### 8.3 ESP 加速 \[pdf\_1]

- `iESPcode=2`（默认）：基于 LIBRAETA 库的快速代码

- 使用 `.fch` 文件且安装了 Gaussian 时，可调用 cubegen 加速 ESP 计算（见第 5.7 节）

- 大体系计算 ESP 网格数据时强烈建议使用 cubegen

### 8.4 绘图设置保存与加载 \[pdf\_1]

在绘图界面（主功能 3、4、5、11）中：输入 `s` 保存，输入 `l` 加载。

### 8.5 轨道等值面质量调节 \[pdf\_1]

- 使用 `Isosur. quality` 滑块实时调节

- 修改 `nprevorbrid` 设置默认网格点数

- 显示大范围轨道（如 Rydberg 轨道）：增大扩展距离（`Aug3D` 或 `Set extension distance`）

### 8.6 分子显示样式 \[pdf\_1]

在 `Other settings` 中选择：CPK 样式、vdW 样式、Line 样式。

### 8.7 成键阈值调节 \[pdf\_1]

默认：原子距离 < CSD 共价半径之和 × 1.15 视为成键。通过 `Bonding threshold` 滑块调节。若输入文件含连接信息（如 `.mol`、`.mol2`），则直接使用。

### 8.8 自定义运算（多个波函数）\[pdf\_1]

在主功能 3、4、5 中，选项 `0` 支持对多个波函数进行自定义运算：

- 支持的运算符：`+`（加）、`-`（减）、`*`（乘）、`/`（除）

- 示例：`a.wfn - b.wfn * c.wfn` → 先计算 a-b，再乘以 c

### 8.9 用户自定义函数 \[pdf\_1]

在 `settings.ini` 中设置 `iuserfunc`：

- `-1`：基于网格数据的三线性插值函数

- `-3`：基于网格数据的三次 B 样条插值

- `10000+i`：选择第 i 个实空间函数（如 `10009` = ELF）

### 8.10 大环原子索引输入 \[pdf\_1]

输入 `d` 再按 `Enter`，可任意顺序输入原子索引，程序自动根据连接关系猜测顺序（当环中某原子连接超过 2 个环内原子时不可用）。

### 8.11 复制输出到文本文件 \[pdf\_2]

- 增大控制台窗口的缓冲区大小（见第 5.5 节）

- 具体复制方法见第 5.4 节

### 8.12 将 `.molden` 转换为 `.mwfn` 加速加载 \[pdf\_1]

使用主功能 100 子功能 2 将 `.molden` 转换为更紧凑的 `.mwfn` 格式。

### 8.13 原子核位置 ESP 的应用 \[pdf\_1]

在 main function 1 中，指定原子核位置时自动输出 Vn（去除该原子核贡献的 ESP），可用于：

- 预测 pKa（J. Phys. Chem. A, 118, 1697 (2014)）

- 预测静电主导的弱相互作用能（H 键、卤键、二氢键）

## 九、常见问题与排查

### 9.1 程序突然退出 \[pdf\_2]

| 原因              | 解决方案                          |
| --------------- | ----------------------------- |
| 输入文件不适合当前任务     | 仔细检查手册相应章节                    |
| 输入文件有问题         | 重新生成或用文本编辑器检查                 |
| 操作步骤不正确         | 重现手册示例                        |
| 内存不足（Win32）     | 换用 Win64 版本，增大 `ompstacksize` |
| Linux 段错误       | 未按第 2.1.2 节配置系统               |
| 依赖 NBO 且使用了弥散函数 | 移去弥散函数后重试                     |
| 程序 bug          | 到官方论坛报告                       |

### 9.2 Windows 下调用 Gaussian 失败 \[pdf\_2]

报错 "No executable for file l1.exe"：设置 `GAUSS_EXEDIR` 环境变量（见手册附录 1）。

### 9.3 找不到导出的文件 \[pdf\_2]

文件总是在**当前文件夹**中生成。

### 9.4 不理解输出文件各列含义 \[pdf\_2]

导出时各列含义总会明确显示在屏幕上。

### 9.5 ESP 计算慢 \[pdf\_2]

大体系计算 ESP 网格数据时，建议调用 Gaussian 的 cubegen 加速（见第 5.7 节）。
