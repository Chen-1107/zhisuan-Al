# 逆合成分析技能手册（完整指令版）

> 本文档基于 MIT 有机合成课程、多种有机化学教材、药物化学手册、工艺研究与开发手册、有机化学问题求解等文献整理，涵盖从基础概念到高级策略的**逆合成分析完整体系**。

## 一、逆合成分析导论

### 1.1 定义与基本概念 [pdf_126]

**逆合成分析（Retrosynthetic Analysis）** 是一种将目标分子（Target Molecule）逐步转化为更简单前体（Precursor）的系统性思考方法。该过程持续进行，直到获得可由商业来源获得或已知方法合成的**起始原料**（Starting Materials）[pdf_126]。

$$ \text{Target Molecule} \xrightarrow{\text{变换（Transform）}} \text{前体} \xrightarrow{\text{变换}} \text{更简单前体} \xrightarrow{\text{继续}} \cdots \xrightarrow{} \text{可用起始原料} $$

**关键术语** [pdf_125][pdf_127]：

| 术语 | 定义 |
|------|------|
| **逆合成（Retrosynthesis）** | 从目标分子向简单前体逆向推导的过程 |
| **变换（Transform）** | 逆合成分析中的每一步反推操作（即**逆反应**） |
| **切断（Disconnection）** | 在逆合成分析中"切断"化学键，将分子拆分为片段 |
| **合成子（Synthon）** | 逆合成分析中产生的**理想化**结构片段（可带正/负电荷） |
| **合成等价体（Synthetic Equivalent）** | 合成子对应的**实际化学试剂** |
| **官能团转化（FGI）** | 将一种官能团转换为另一种 |
| **前体（Precursor）** | 目标分子向回推一步得到的化合物 |

### 1.2 策略与战术的区别 [pdf_125][pdf_127]

| 层面 | 策略（Strategy） | 战术（Tactics） |
|------|-----------------|-----------------|
| **性质** | 智力层面（intellectual） | 实验层面（experimental） |
| **内容** | 逆合成规划（retrosynthetic planning） | 合成执行（synthetic execution） |
| **核心操作** | 变换（Transforms） | 反应（Reactions） |
| **对象** | 目标分子 → 前体 | 前体 → 目标分子 |

### 1.3 逆合成分析的第一原则 [pdf_125]

> **收敛策略（Convergent Strategies）是组装复杂分子最高效的策略。**

## 二、逆合成基本策略

### 2.1 收敛合成 vs 线性合成 [pdf_125]

**线性合成（Linear Synthesis）**：A → B → C → D → E → 目标
**收敛合成（Convergent Synthesis）**：A → B → C 和 D → E → F 分别组装后 → G → 目标

**定量对比**（每步产率按 70% 计算）[pdf_125][pdf_127]：

| 指标 | 9步线性合成 | 7步线性合成 | 3步收敛合成 |
|------|:----------:|:----------:|:----------:|
| 所需起始原料 | 62.1 g | 20.8 g | 20.4 g |
| 总溶剂用量 | 3278 mL | 714 mL | 346 mL |
| 总产率（70%每步） | \(0.7^9 \approx 4.0\%\) | \(0.7^7 \approx 8.2\%\) | \(0.7^3 \approx 34.3\%\) |

**结论**：收敛路线用**更少的步骤、更少的原料和溶剂**即可获得相同产物，且总产率更高。

### 2.2 合成效率的维度 [pdf_127]

**战略效率（Strategic Efficiency）**：
- 最少步骤（Minimum # Steps）
- 收敛性（Convergence）

**战术效率（Tactical Efficiency）**：
- 高产率（High Yield）
- 原子经济性（Atom Economy）

**选择性（Selectivity）**：
- **化学选择性（Chemoselectivity）**：在多官能团分子中选择性反应一个位点
- **区域选择性（Regioselectivity）**：在多个可能反应位点中选择特定位置
- **立体选择性（Stereoselectivity）**：控制产物的立体化学

### 2.3 新合成路线设计原则 [pdf_124]

1. **优先使用商业可得、价格低的原料**
2. **优先使用催化体系**（而非当量试剂）
3. **限制保护基操作次数**（保护基操作增加步骤、降低效率）
4. **优先使用收敛路线**而非线性路线
5. **优先使用加成反应**（原子经济性高）
6. **优先使用多组分反应（MCRs）**
7. **优先使用串联或级联反应（tandem/cascade processes）**

## 三、逆合成分析中的切断策略

### 3.1 切断的基本规则

**切断（Disconnection）** 是逆合成分析的核心操作。切断化学键时应遵循以下原则：

**优先切断的位置** [pdf_129]：
1. **支化点**（branching points）——可简化分子骨架
2. **杂原子附近**——C-X 键比 C-C 键更容易切断
3. **官能团β位**——β-切断往往对应常见的反应（如 Aldol 反应）
4. **环状结构的关键键**——如 Diels-Alder 环加成反应的逆分析

**切断操作的基本原则**：
- 切断的键应对应于**已知的反应**（称为"逆反应"）
- 切断后产生的两个片段应可通过实际化学反应连接
- 优先选择极性匹配的切断（**极性化切断**）

### 3.2 合成子与极性匹配 [pdf_129]

**合成子（Synthon）** 是逆合成分析中产生的理想化片段，通常带有形式电荷：

$$ \text{目标分子} \xrightarrow{\text{切断}} \text{合成子 A}^+ + \text{合成子 B}^- \xrightarrow{\text{寻找等价体}} \text{实际试剂} $$

**极性反转（Umpolung）**：当常规极性无法实现所需切断时，需要极性反转策略。

### 3.3 常见逆合成切断模式

**1. 醇类（Alcohols）**：
- 切断 C-OH 键 → 对应 Grignard 反应 / 还原
- 切断 β-羟基 C-C 键 → 对应 Aldol 反应逆反应

**2. 羰基化合物**：
- 切断 α,β-不饱和键 → 对应 Wittig / Horner-Wadsworth-Emmons 逆反应
- 切断 β-二羰基 → 对应 Claisen 缩合逆反应

**3. 烯烃**：
- 切断 C=C → 对应 Wittig 反应逆反应 / 烯烃复分解 / 消除反应

**4. 环状化合物**：
- 环己烯 → Diels-Alder 反应逆反应（切断两处 C-C 键）
- 环丙烷 → Simmons-Smith 反应逆反应

**5. 芳香族化合物**：
- 取代芳烃 → 切断取代基，逆推至亲电/亲核取代反应

### 3.4 FA（Fragment Analysis）策略 [pdf_129]

**FA（Fragmentation Analysis）** 是一种将目标化合物按**起始原料片段**进行拆解的系统性技术：

- 在目标分子中标记起源于起始原料的**公共片段**
- 在片段边界发现**键连接/断开点**
- 基于此提出一个或多个假设性反应机理

**FA 的基本步骤** [pdf_129]：
1. 在目标分子中识别起始原料中存在的**结构碎片**
2. 用虚线标记碎片边界
3. 分析边界处的键连接/断开
4. 对每个连接/断开点，提出合理的反应机理
5. 综合所有可能性，评估最可行的路线

## 四、官能团转化（FGI）

### 4.1 FGI 在逆合成中的作用 [pdf_51]

**官能团转化（Functional Group Interconversion, FGI）** 是逆合成分析中简化目标分子的关键方法。通过将目标分子中的一个官能团转换为另一个更简单的官能团，可以为切断创造条件。

**FGI 的分类** [pdf_51]：

| 类型 | 示例 | 说明 |
|------|------|------|
| 氧化 | 醇 → 醛/酮 → 羧酸 | 增加氧化态 |
| 还原 | 羰基 → 醇 → 烷烃 | 降低氧化态 |
| 取代 | 卤代物 → 醇 → 胺 | 官能团互换 |
| 消除 | 醇 → 烯烃 | 去除官能团 |
| 加成 | 烯烃 → 醇 | 引入官能团 |

### 4.2 常见 FGI 逆合成

| 目标分子中的官能团 | FGI 后获得 | 对应正向反应 |
|-------------------|------------|------------|
| 醇 | 羰基（C=O） | 还原 |
| 羰基 | 烯烃（C=C） | 氧化/水合 |
| 卤代物 | 醇 | 取代 |
| 酯 | 酸 + 醇 | 酯化逆反应 |
| 酰胺 | 酸 + 胺 | 酰胺化逆反应 |
| 醚 | 醇 + 卤代物 | Williamson 醚合成逆反应 |
| 烯烃 | 卤代物/醇 | 消除逆反应 |

### 4.3 药物化学中的反应频率 [pdf_128]

在药物发现中，最常用的反应类型及其频率：

| 反应类型 | 使用频率 |
|----------|:--------:|
| 烷基化（Alkylation） | 40% |
| 酰化/磺酰化（Acylation） | 25% |
| C-C 键形成 | 20% |
| 官能团转化（FGI） | 15% |
| 保护基操作 | 5% |
| 杂环形成 | 5% |
| 氧化/还原 | 各 2% |
| 有机金属 | 1% |

## 五、保护基策略

### 5.1 保护基的作用 [pdf_124]

保护基（Protecting Group）在逆合成分析中扮演重要角色：
1. **屏蔽反应性位点**，使反应选择性地发生在指定位置
2. **作为空间屏障**，引导试剂作用于特定区域 [pdf_129]
3. **作为辅助诱导立体选择性**
4. 保护基操作应**尽量少**，每条路线不超过 1-2 次保护/脱保护

### 5.2 常见保护基速查 [pdf_124]

**醇/酚的保护**：

| 保护基 | 缩写 | 引入 | 脱除 |
|--------|:----:|------|------|
| 三甲基硅基 | TMS | TMSCl, 咪唑 | 酸或 F⁻ |
| 叔丁基二甲基硅基 | TBS/TBDMS | TBSCl, 咪唑, DMF | TBAF 或酸 |
| 四氢吡喃基 | THP | DHP, PPTS | 酸 (H⁺, H₂O) |
| 苄基 | Bn | BnBr, NaH | H₂, Pd/C |
| 对甲氧基苄基 | PMB | PMBCl, NaH | DDQ 或酸 |
| 乙酰基 | Ac | Ac₂O, 吡啶 | 碱 (K₂CO₃, MeOH) |
| 苯甲酰基 | Bz | BzCl, 吡啶 | 碱 |

**胺的保护**：

| 保护基 | 缩写 | 引入 | 脱除 |
|--------|:----:|------|------|
| 叔丁氧羰基 | Boc | Boc₂O, 碱 | TFA 或 HCl |
| 苄氧羰基 | Cbz/Z | CbzCl, 碱 | H₂, Pd/C |
| 苄基 | Bn | BnBr, 碱 | H₂, Pd/C |
| 三氯乙氧羰基 | Troc/Tce | TrocCl, 碱 | Zn/AcOH |
| 芴甲氧羰基 | Fmoc | FmocCl, 碱 | 哌啶 |

**羰基的保护**：

| 保护基 | 引入 | 脱除 |
|--------|------|------|
| 缩醛/缩酮 | 二醇, H⁺ | 酸 (H⁺, H₂O) |
| 1,3-二噻烷 | 1,3-二噻烷, BF₃ | HgCl₂/CaCO₃ |

**羧酸的保护**：

| 保护基 | 引入 | 脱除 |
|--------|------|------|
| 甲酯 | MeOH, H⁺ | 碱 (LiOH) |
| 叔丁酯 | t-BuOH, DCC | TFA |
| 苄酯 | BnOH, DCC | H₂, Pd/C |

### 5.3 保护基选择原则 [pdf_124]

1. **正交性**：不同保护基可用不同条件选择性脱除
2. **稳定性**：在后续反应条件下稳定
3. **引入条件温和**：不干扰其他官能团
4. **脱除条件温和**：不破坏产物
5. **高原子经济性**：尽量避免引入大分子保护基

## 六、逆合成分析的系统性方法

### 6.1 整体分析框架 [pdf_129]

1. **识别官能团**：列出目标分子中所有官能团
2. **评估复杂性**：识别手性中心、环系、骨架支化点
3. **选择第一次切断**：从最关键的 C-C 键或最易简化的位置开始
4. **应用 FGI**：将复杂官能团转化为更简单的形式
5. **重复逆推**：直到所有片段为可用起始原料
6. **评估路线**：比较不同路线，选择最优方案

### 6.2 环状化合物的逆合成策略 [pdf_125][pdf_127]

环状化合物的组装策略分为三大类：

**1. 环化反应（Cyclization）**
- 分子内亲核取代（如：卤代物 + 亲核试剂）
- 分子内 Aldol 反应
- 分子内 Dieckmann 缩合

**2. 成环反应（Annulation）**
- **协同环加成（Concerted Cycloadditions）**：
  - Diels-Alder 反应（[4+2] 环加成）
  - [3+2] 偶极环加成
  - [2+2] 环加成
- **非协同"单操作"成环（Non-Concerted Single-Operation Annulations）**
- **多步成环策略（Multistep Annulation Strategies）**

**3. 串联反应（Tandem/Cascade Reactions）**
- 多步反应在一锅中连续进行
- 最大限度提高原子经济性和步骤经济性

### 6.3 立体化学控制策略 [pdf_145][pdf_209]

**底物控制（Substrate Control）**：
- 利用分子中已有的手性中心诱导新立体中心
- 通过 1,2-或 1,3-不对称诱导实现

**试剂控制（Reagent Control）**：
- 使用手性催化剂或手性试剂控制立体化学
- 例如：CBS 还原、Noyori 不对称氢化、Sharpless 环氧化

**辅助基控制（Auxiliary Control）**：
- 在底物上连接手性辅助基
- 反应后脱除辅助基

**动力学拆分 / 动态动力学拆分**：
- 利用不同对映体反应速率差异实现分离

### 6.4 逆合成分析中的常见陷阱 [pdf_129]

1. **忽略保护基需求**：多官能团分子中反应选择性是关键
2. **忽略立体化学**：不能仅在平面结构上分析
3. **切断位置不合理**：切断必须对应已知反应
4. **路线过长**：每步有产率损失，尽量减少步骤
5. **忽略官能团兼容性**：后续反应条件可能破坏已有官能团

## 七、手性合成与逆合成

### 7.1 手性合成策略 [pdf_145][pdf_146]

**手性池（Chiral Pool）**：使用天然手性化合物作为起始原料
- 氨基酸、糖类、萜类、生物碱
- 优点：立体化学已确定，无需不对称诱导

**不对称合成（Asymmetric Synthesis）**：
- 使用手性催化剂或手性试剂
- 通过底物控制或试剂控制实现

**外消旋体拆分（Resolution）**：
- 经典拆分（手性酸/碱）
- 动力学拆分
- 酶促拆分

### 7.2 手性控制策略选择 [pdf_145][pdf_154]

| 策略 | 优点 | 缺点 |
|------|------|------|
| 手性池 | 立体化学确定，天然来源 | 结构选择有限 |
| 底物控制 | 利用已有手性中心 | 需要强底物偏好 |
| 试剂控制 | 可适用于两种对映体 | 需要强偏好试剂 |
| 拆分 | 技术成熟 | 最高产率仅 50% |
| 动态动力学拆分 | 理论产率可达 100% | 条件苛刻 |

## 八、逆合成示例分析

### 8.1 示例：醇的逆合成

**目标**：2-甲基-2-戊醇

```
       OH
       |
CH₃—C—CH₂—CH₂—CH₃
       |
      CH₃
```

**切断 A（Grignard 反应）**：
```
        OH
        |
CH₃—C—CH₂—CH₂—CH₃   ←   CH₃—C(=O)—CH₂—CH₂—CH₃ + CH₃MgBr
        |
       CH₃
```

**切断 B（Grignard 反应，另一种方式）**：
```
        OH
        |
CH₃—C—CH₂—CH₂—CH₃   ←   CH₃—C(=O)—CH₃ + CH₃—CH₂—CH₂—MgBr
        |
       CH₃
```

**评估**：两条路线均可行，取决于哪种原料更易得。

### 8.2 示例：Diels-Alder 逆合成 [pdf_125][pdf_127]

**目标**：环己烯衍生物

```
      CO₂CH₃
      |
       \
        \
         \   ← 切断此处
          \
       /    \
      /      \
     /        \
    \          \
     \          |
      \    CO₂CH₃
       \
```

**逆合成分析**：
```
目标分子  ←  Diels-Alder 逆反应 →  丁二烯（二烯体）+ 马来酸二甲酯（亲二烯体）
```

Diels-Alder 反应的逆合成是最经典的逆合成变换之一，具有以下优势 [pdf_125]：
- 一步构建两个 C-C 键和一个六元环
- 高度立体选择性（内/外规则）
- 原子经济性为 100%

### 8.3 示例：Robinson 关环（Annulation）逆合成

Robinson 关环反应是合成环己烯酮衍生物的重要方法，其逆合成分析为：

```
目标分子（环己烯酮）  ←  切断 C-C 键 →  β-酮酯 +  α,β-不饱和酮（Michael 受体）
                      ←  再切断 →  Michael 加成 + Aldol 缩合
```

### 8.4 示例：复杂天然产物的逆合成 [pdf_128]

**AMG-176 的合成路线设计** [pdf_128]：

AMG-176 是一种 Bcl-2/Mcl-1 抑制剂，其合成路线设计展示了收敛合成的力量：

- 从简单的氯代二氢萘酮出发
- 通过选择性单酰化和 Kang 催化剂的去对称化构建关键螺环-苯并氮杂䓬
- 通过酶促去酰化进行第二次去对称化
- 总最长线性步数约 20 步
- **关键中间体 7 的合成仅需 4 步，总产率 70%**

### 8.5 片段分析（FA）示例 [pdf_129]

**问题**：从目标产物倒推反应机理

FA 的核心思想：
1. 在目标分子中标记起始原料中存在的**分子片段**
2. 在片段边界发现**键连接/断开点**
3. 基于此提出**假设性反应机理**

**应用示例** [pdf_129]：

在杯珊瑚素（cuparenone）的逆合成分析中：
- 将目标分子按起始原料片段进行拆解（虚线标记）
- 在片段边界处发现 C-C 键连接点
- 预测可能的环化反应机理
- 设计可实验验证的合成路线

## 九、计算辅助逆合成

### 9.1 计算机辅助合成设计 [pdf_128][pdf_126]

**OCSS（Organic Chemical Simulation of Synthesis）** [pdf_128]：
- 由 Corey 和 Wipke 在 1960 年代末开发
- 第一个计算机辅助合成设计系统
- 核心思想：将化学知识编码为规则，由计算机自动搜索合成路线

### 9.2 基于规则的方法 [pdf_126]

**基本原理**：
- 由专家化学家编码反应规则（transformation rules）
- 将规则应用于目标分子，生成前体
- 使用蒙特卡洛树搜索（Monte Carlo Tree Search）探索合成路线
- 结合三个神经网络选择候选反应

**局限性**：
- 对于超出规则范围的分子效果不佳
- 规则更新需要大量人工维护

### 9.3 深度学习方法 [pdf_126]

**优势**：
- 能从大量数据集中提取通用模式
- 不依赖人工编码的固定规则
- 可处理新型分子和未知反应类型

**实现方式**：
- 目标分子以 **SMILES 字符串**编码
- 神经网络学习从目标分子 SMILES 到反应物 SMILES 的映射
- 从大规模反应数据库中学习反应模式

### 9.4 合成路线预测的挑战 [pdf_128]

据估计，在 15 步或更少的反应路线中，平均有约 \(3.5 \times 10^{28}\) 种可能路线，每条路线都有特定的反应性约束，取决于所使用的起始原料 [pdf_128]。

## 十、逆合成分析的完整工作流

### 10.1 标准分析流程

```
目标分子
    ↓
1. 识别所有官能团
    ↓
2. 评估分子 Complexity（环系、手性中心、骨架）
    ↓
3. 选择关键切断位点
    ↓
4. 应用 FGI 简化官能团
    ↓
5. 重复切断 → 逐步简化
    ↓
6. 得到可用起始原料
    ↓
7. 评估各路线（产率、成本、立体化学、安全性）
    ↓
最终合成路线
```

### 10.2 合成路线评估标准 [pdf_124]

| 评估维度 | 问题 |
|----------|------|
| **原料可及性** | 是否商业可得？价格是否合理？ |
| **步骤总数** | 最长线性步数是多少？ |
| **总产率** | 按每步合理产率估算总产率 |
| **立体化学** | 手性控制策略是否可靠？ |
| **选择性** | 是否存在选择性问题？ |
| **保护基** | 需要多少保护/脱保护步骤？ |
| **安全性** | 是否涉及危险试剂或条件？ |
| **可放大性** | 是否适合大规模合成？ |
| **原子经济性** | 是否产生大量副产物？ |

### 11.1 常见逆合成变换速查

| 目标结构 | 切断方式 | 对应正向反应 |
|----------|----------|------------|
| 醇 \(R_2C(OH)-R'\) | 切断 C-OH 或 C-C(OH) | Grignard / 还原 |
| 羰基 \(R_2C=O\) | 切断相邻 C-C | 氧化 / Wittig |
| 烯烃 \(R_2C=CR_2\) | 切断 C=C | Wittig / 烯烃复分解 |
| 环己烯 | 切断 2 处 C-C | Diels-Alder |
| 1,3-二羰基 | 切断中间 C-C | Claisen 缩合 |
| β-羟基羰基 | 切断 C-C(OH) | Aldol 反应 |
| 环丙烷 | 切断 C-C | Simmons-Smith |
| 醚 \(R-O-R'\) | 切断 C-O | Williamson 醚合成 |
| 酯 \(RCO_2R'\) | 切断 C-O(羰基) | 酯化 |
| 酰胺 \(RCONR'R''\) | 切断 C-N | 酰胺化 |
