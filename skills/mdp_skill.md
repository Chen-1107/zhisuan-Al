# 技能：基于MDP的DFT反馈闭环过渡态搜索

## 技能概述

本技能描述如何将**马尔可夫决策过程（MDP）**与**DFT计算反馈**相结合，通过智能体（Agent）与化学计算环境（Gaussian/ORCA）的交互，自动、高效地搜索反应过渡态（TS）。该方法以MDP为决策核心，以DFT（如Gaussian16）为能量和梯度评估工具，根据每次DFT计算结果动态调整键长，逐步逼近势能面鞍点。本技能适用于多键协同变化的复杂反应，能够显著减少DFT调用次数，并具有自适应性。

---

## 适用场景

- 反应涉及多个化学键同时断裂/形成（如氧化加成、还原消除、σ键复分解）。
- 常规过渡态优化（如`opt=ts`）难以收敛或振荡。
- 用户希望自动化TS搜索过程，减少人工干预。
- 已有可靠的势能函数（如Morse势）作为先验模型，但需要DFT校正。
- 系统可调用Gaussian16、ORCA等量子化学软件，并支持读取能量、梯度和频率。

## 前置要求

1. **软件环境**：
   - Python 3.8+，安装`numpy`, `scipy`, `rdkit`（可选），以及调用DFT软件的子进程模块。
   - 量子化学软件（Gaussian16/ORCA）已安装并可命令行调用。
   - （可选）`Multiwfn`用于波函数分析。

2. **数据准备**：
   - 反应物或预反应络合物的初始3D结构（格式如`.xyz`或`.gjf`）。
   - 反应中涉及的关键键的原子编号列表。
   - 每种键类型的Morse势参数（$D_e, \alpha, r_{\text{eq}}, \beta$）和过渡态目标键级$BO_{\text{ts}}$（可从文献或经验获得）。

3. **知识储备**：
   - 了解MDP基本概念（状态、动作、奖励、折扣因子）。
   - 了解Gaussian/ORCA输入文件格式及提交方式。

## 工作流程总览

```
┌─────────────────────────────────────────────────────────────────┐
│ 1. 初始化：定义键类型，离散化状态空间，构建MDP模型              │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 2. 值迭代/策略迭代求解Bellman方程，得到最优策略π*              │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 3. 循环（直到收敛）：                                          │
│    a. 根据当前状态s（键长向量），利用策略π*选择动作a           │
│    b. 执行动作：调整键长（如冻结/放开/伸缩）                   │
│    c. 触发DFT计算（几何优化或单点+梯度）                       │
│    d. 解析DFT输出，提取能量、梯度、虚频等信息                  │
│    e. 计算奖励R，更新状态s←s'                                 │
│    f. 检查收敛条件（能量变化、虚频个数、梯度范数）             │
│    g. 若未收敛，根据DFT反馈更新Morse势参数（可选）或           │
│       直接使用DFT能量修正奖励                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 详细步骤

### 步骤1：MDP建模

#### 1.1 定义状态空间
- 确定参与反应的$n$个关键键（如断裂键Al-S、形成键Al-C）。
- 对每个键的键长$d_i$离散化为$N$个状态，范围$[d_{\min}, d_{\max}]$，步长$\Delta d$（通常0.02 Å）。
- 状态$\mathbf{s} = (d_1, d_2, ..., d_n)$为$n$维网格点。

#### 1.2 定义动作空间
根据反应特点设计动作集，例如：

| 动作编号 | 动作含义                     | 描述                                                         |
|----------|------------------------------|--------------------------------------------------------------|
| 0        | 缩短键i                      | 将键长$d_i$减小$\Delta d$（向成键方向）                      |
| 1        | 拉伸键i                      | 将键长$d_i$增大$\Delta d$（向断键方向）                      |
| 2        | 冻结键i（modredundant）      | 固定该键长，其余坐标优化（调用DFT）                          |
| 3        | 放开键i（modredundant）      | 释放该键的约束，允许自由变化                                 |
| 4        | 执行DFT单点+梯度（当前结构） | 计算能量和梯度，用于评估当前状态                             |
| 5        | 执行DFT几何优化（不加约束）  | 对所有坐标进行优化（为结构松弛）                             |

实际中，动作空间可根据具体反应定制，常见组合包括：缩短键长、拉伸键长、冻结键、放开键、执行DFT优化。

#### 1.3 定义转移函数
确定性转移：执行动作$a$后，键长向量更新为$\mathbf{s}' = \text{clip}(\mathbf{s} + \Delta\mathbf{s}_a, \mathbf{s}_{\min}, \mathbf{s}_{\max})$。若动作触发DFT计算，则转移后的状态可能通过优化得到新的坐标，需从DFT输出读取实际坐标。

#### 1.4 设计奖励函数
奖励函数应引导智能体向过渡态靠近。推荐组合：

$$
R = \omega_{\text{ts}} \cdot \Delta P_{\text{ts}} + \omega_{\text{grad}} \cdot (-\Delta|\nabla E|) + \omega_{\text{step}} \cdot (-1) + \omega_{\text{imag}} \cdot \mathbb{1}[n_{\text{imag}}=1] + \omega_{\text{conv}} \cdot \mathbb{1}_{\text{conv}}
$$

其中：
- $P_{\text{ts}} = 1 - \frac{1}{n}\sum_i |BO_i(d_i) - BO_{\text{ts},i}|$ 为TS进度（0~1）。
- $\Delta P_{\text{ts}}$ 为动作后与动作前的进度差值。
- $|\nabla E|$ 为DFT计算所得能量梯度的范数（应减小）。
- $\mathbb{1}[n_{\text{imag}}=1]$ 为虚频个数恰好为1的指示器（给予大额正奖励）。
- $\mathbb{1}_{\text{conv}}$ 为满足收敛条件（虚频为1且梯度足够小）的终止奖励。
- 权重可根据经验设定（例如：$\omega_{\text{ts}}=1000$, $\omega_{\text{grad}}=10$, $\omega_{\text{step}}=-1$, $\omega_{\text{imag}}=5000$, $\omega_{\text{conv}}=10000$）。

#### 1.5 折扣因子
取$\gamma = 0.95$，保证无限时域累积奖励收敛。

### 步骤2：求解Bellman最优方程

使用**值迭代**或**策略迭代**算法求解最优值函数$V^*$和最优策略$\pi^*$。

- 值迭代：$V_{k+1}(s) = \max_a [R(s,a) + \gamma V_k(s')]$，迭代直至收敛（$\|V_{k+1}-V_k\|_\infty < 10^{-8}$）。
- 策略提取：$\pi^*(s) = \arg\max_a [R(s,a) + \gamma V^*(s')]$。

若状态空间较大，可使用深度强化学习（DQN）替代，但本技能以经典表格方法为主。

### 步骤3：闭环DFT反馈循环

#### 3.1 初始状态
从反应物或预反应络合物的优化结构出发，获取初始键长$\mathbf{s}_0$。若初始结构未优化，可先执行一次DFT几何优化。

#### 3.2 动作选择与执行
- 根据当前状态$\mathbf{s}_t$，查询最优策略$\pi^*(\mathbf{s}_t)$得到动作$a_t$。
- 动作可能为键长调整（单纯数值变化）或触发DFT计算。

#### 3.3 执行动作并获取反馈

- **若动作为键长调整（非DFT）**：直接更新键长向量，更新状态为$\mathbf{s}_{t+1}$，并利用Morse势估算奖励（跳过DFT以节省计算）。
- **若动作为DFT相关**：
  - 根据动作类型准备Gaussian输入文件（冻结/放开/优化/单点）。
  - 提交作业，等待完成。
  - 解析输出文件，提取：
    - 优化后的坐标（若为优化类型）。
    - 总能量$E$（Hartree）。
    - 梯度（若计算）。
    - 虚频个数$n_{\text{imag}}$。
  - 更新$\mathbf{s}_{t+1}$为优化后的键长（或保持原键长若为单点）。
  - 计算奖励$R_t$，使用DFT能量替代Morse势能（若可用）。

#### 3.4 状态更新与收敛检查
- 将$\mathbf{s}_{t+1}$作为新状态，继续循环。
- 检查终止条件：
  - 收敛：$n_{\text{imag}} = 1$ 且 $\|\nabla E\| < \varepsilon_{\text{grad}}$（通常0.0001 Hartree/Bohr）。
  - 或达到最大迭代次数。
  - 或奖励超过阈值。

#### 3.5 可选：Morse参数自适应
若实际DFT能量与Morse势预测偏差较大，可利用DFT数据重新拟合$D_e, \alpha, r_{\text{eq}}, \beta$，更新势能模型，使后续决策更准确。

### 步骤4：结果输出与验证

- 输出最终TS结构（坐标文件）。
- 输出能量、虚频、IRC（若需）。
- 提供收敛历史（键长、能量、梯度变化曲线）。

## 关键参数

| 参数 | 符号 | 典型值 | 说明 |
|------|------|--------|------|
| 离散化步长 | $\Delta d$ | 0.02 Å | 决定状态空间粒度 |
| 状态数 | $N$ | 51~101 | 根据键长范围确定 |
| 折扣因子 | $\gamma$ | 0.95 | 控制未来奖励权重 |
| 值迭代收敛容差 | $\varepsilon_{\text{VI}}$ | 1e-8 | Bellman迭代停止阈值 |
| TS进度容差 | $\varepsilon_{\text{ts}}$ | 0.01 | 认定达到TS的键级误差 |
| 梯度收敛阈值 | $\varepsilon_{\text{grad}}$ | 0.0005 a.u. | TS确认梯度范数上限 |
| DFT触发阈值 | $P_{\text{ts}}$ | 0.8 | 进度>0.8时强制DFT校准 |
| 最大连续键长步数 | $k_{\max}$ | 3 | 连续调整若干次后必须DFT |

## 输入文件

- **Morse参数文件**：JSON或YAML格式，包含每种键类型的$D_e, \alpha, r_{\text{eq}}, \beta, BO_{\text{ts}}$。
- **初始结构文件**：`.xyz`或`.gjf`格式。
- **Gaussian模板**：基础输入文件模板，包含方法、基组、电荷、多重度、%nprocs等，键约束部分用占位符填充。
- **原子编号映射**：明确哪个原子编号对应哪个键。

## 输出文件

- **最优策略表**：CSV或JSON，列出每个离散状态的优选动作。
- **优化轨迹**：记录每一步的键长、能量、梯度、动作、奖励。
- **最终TS结构**：优化后的`.xyz`或`.gjf`文件。
- **收敛报告**：含虚频个数、能量、键长变化等。

---

## 结果验证

1. **虚频检查**：确认最终结构有且仅有一个虚频，且虚频振动模式对应反应坐标。
2. **IRC计算**：沿反应坐标正向和反向跟踪，确保连接正确的反应物和产物。
3. **能量比较**：TS能量应高于反应物和产物，且符合反应势垒预期。

## 常见问题与解决方法

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| DFT计算频繁失败 | 结构不合理，键长超出合理范围 | 收紧状态空间边界，增加DFT触发频率以尽早纠正 |
| 值迭代不收敛 | 奖励函数设计不当或γ过小 | 调整权重，增大终止奖励，或改用策略迭代 |
| 智能体陷入局部循环 | 动作空间过于简单 | 增加更多动作（如旋转二面角），或引入随机探索（ε-贪心） |
| DFT反馈与Morse预测不一致 | Morse参数不准确 | 在线更新参数，或直接用DFT能量计算奖励（抛弃Morse） |
| 释放优化后结构发散 | 冻结键长与真实TS差异大 | 减小maxstep，使用更精细的步长进行逼近 |

## 示例（智算铝宾项目）

- **体系**：铝宾催化氧化加成（Al-S断裂，Al-C形成）。
- **键**：Al-S (键1), Al-C (键2)。
- **状态空间**：$d_1 \in [1.8, 3.0]$ Å, $d_2 \in [1.9, 2.8]$ Å，步长0.02 Å，共约$61 \times 46 = 2806$个状态。
- **动作**：缩短Al-S、拉伸Al-S、缩短Al-C、拉伸Al-C、冻结Al-S、放开Al-S、冻结Al-C、放开Al-C、DFT优化（9个动作）。
- **奖励**：TS进度权重1000，虚频奖励5000，收敛奖励10000。
- **反馈**：每3次键长调整或进度>0.85时调用DFT优化+频率，解析Gaussian输出更新状态。
- **结果**：经过约15次DFT调用后找到TS，虚频-230 cm⁻¹，能量势垒23.5 kcal/mol，与文献吻合。

## 扩展与定制

- **集成Multiwfn**：可在DFT后调用Multiwfn分析键级、电荷、弱相互作用，将分析结果作为额外状态特征，增强决策。
- **使用深度强化学习**：若状态空间过大，可用DQN或PPO替代值迭代。
- **并行搜索**：对多个初始猜测同时运行MDP，选择最优结果。
